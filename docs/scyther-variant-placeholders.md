- Add a Scyther evolution specialist / stone collector in the Safari Zone.
- Player brings a normal Scyther and chooses an available evolutionary branch.
- Intended branches currently:
  - Scizor
  - Kleavor
  - Ice branch
  - Ghost branch
  - Electric branch
  - Fire branch once suitable art is found
- Exact stone names, stats, typings, abilities, and evolution implementation remain TBD for custom branches.

- Do not overwrite official/custom species assets in master with placeholder art without an explicit implementation decision.
- Before vendoring any third-party binary sprite assets, verify source/license/permission and credit requirements.
- This document exists so the current candidates remain easy to find across Work sessions.
