# Chaos FireRed — Kanto alpha playthrough

Built October 6, 2026. Goal: test a normal start-to-Champion playthrough while the expanded postgame story is unfinished.

Start a fresh save for the main test. Back up your existing Delta save; avoid loading a save state created with an older ROM. Existing in-game saves have reward-retry compatibility, but a fresh run is best for finding event-order problems.

## New in this alpha

- Oak gives Mega Ring and Nidokingite together outside Sabrina's Gym after Marsh Badge. Cinnabar no longer reveals Nidokingite. Missing the optional Strange Fossil does not block the reward; a full bag can retry.
- Lavender: ASHBY in Mr. Fuji's volunteer house offers a one-Pokemon challenge against Mega Arcanine. Win Arcanite, then use it on normal Arcanine after obtaining Mega Ring. Native front/back/shiny sprites and visible item icons are present.
- Both rewards persist and cannot be farmed. Challenge win/loss restores the full party; normal difficulty rules still apply.
- Includes the BST redesign: Shuffle preserves the normal total; Random generates each stat independently, usually 5–160, with rare 161–220 rolls and evolution safeguards.

## Priority playthrough checkpoints

1. Choose your intended run settings. Check all three starter balls, the rival battle, and save/reload. Random starters without filters should be base stages.
2. Enter the Bike Shop normally: the greeting and Bicycle gift should trigger automatically. Check normal item balls and hidden pickups with your chosen Random Items setting.
3. Test first Center heal, PC/Pokevial, Ranch return and illegal-party exit behavior if using filters. Try a loss before healing at a Center, then another after recording one.
4. Follow ordinary Rocket/Mr. Fuji/Silph progression. Visit Lavender's Arcanine specialist, including cancel, win and loss. A full bag must leave the stone claimable.
5. Beat Erika, then test Chaos Arcade access, coins, games and separate prize categories.
6. Beat Sabrina before Fuchsia/Koga. On leaving the Gym, Oak should give BOTH Mega Ring and Nidokingite. Check the fossil exchange, a full-bag retry if convenient, and player Mega Nidoking/Arcanine. The post-Marsh Celadon special-stock clerk and Brock/Misty/Surge rematches should be available.
7. Continue through Koga's double battle, Blaine, Giovanni, Victory Road, Elite Four and Champion. Save/reload at several milestones.

If anything fails, send the location, action just before failure, run settings and a screenshot. A save immediately before the problem is especially useful.

## What remains unfinished

The expanded Mewtwo/Giovanni partner battle, Pallet/Chaossal crisis, Gym Leader succession/simulator and Scyther branches are not part of this alpha. A complete natural-acquisition roster is also still pending. Mega Stone item icons reuse existing native art.

The ROM compiles and targeted progression/recovery/event checks pass. A complete human playthrough has not yet been performed, so this is not a guarantee of an error-free game.
