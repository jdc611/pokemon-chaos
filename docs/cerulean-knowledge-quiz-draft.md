# Cerulean knowledge challenge — draft bank

Approved for implementation as a draft bank on Oct. 4, 2026. Each attempt draws one question from each tier; the tiers are hidden in the game. Three correct answers unlock the existing Nature, Ability and Gender quick tools. Answers rotate positions, and a retry excludes the last question seen in each tier.

| Which type is immune to POISON moves? | GRASS / FAIRY / STEEL | STEEL |

| Which type of move is super effective against STEEL? | FAIRY / FIGHTING / GRASS | FIGHTING |
